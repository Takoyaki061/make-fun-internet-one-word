One word for the whole internet: **Doomscroll** — the act of scrolling through bad news, outrage and nonsense long past the point of wanting to, because the feed never ends and neither does the finger. Funny because everyone does it, fitting because it is the internet's defining mass behaviour: not one app, not one mood, the whole machine running on one more scroll.

Entry for make.fun's ["The Internet in One Word"](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b) bounty.

## Run it

```sh
python3 main.py
```

Writes the word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT/entry.txt`).
